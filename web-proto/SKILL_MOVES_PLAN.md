# 슬롯 액티브 전용 동작 계획 (2026-11-10, 작성 전)

기준: `기획서/스킬_슬롯_카탈로그.md` 8절(파츠 80개), 12절 '구현 범위'. 새 액티브 25개 + 흡입(지금 동작 없음) = **26개**를 `src/moves.js` 끝의 `Object.assign(moves, {...})`에 추가합니다. move 이름 = 파츠 id.

## 확인한 것
- 형식: `HANDOFF.md` 4절. 무기 키는 `S(t, u, d)`, 루트 공간 +Z 앞 · +X 오른쪽 · +Y 위. pelvis +Y = 오른쪽으로 돎(왼쪽 어깨가 앞으로). yaw 음수 = 왼쪽으로 돎.
- 왼팔 FK: `LupperArm` -X = 앞으로, -Z = 옆으로. `Lforearm` -X = 팔꿈치 굽힘.
- 감사 기준값(기존 동작, `__proto.audit()`): `blade in body (final)` 없음, `elbow in torso (after fix)` ≤ 0.016, `planted foot error` ≤ 0.09. `before fix`와 `limit LupperArm`(최대 43)은 기존에도 있음. 새 동작도 이 범위 안이어야 합니다.
- 안전한 칼 방향(기존 데이터): `IDLE_UD`, `OUT`, `L1_END`, `L2_END`, `SWEEP_END`, `CHARGE`, 막기 `[.20,-.40,.89]/[-.30,.95,.10]`, 뒤로 늘어뜨림(dash) `[.30,-.85,-.30]/[.45,-.85,-.25]`.
- 왼팔 스킬은 몸을 오른쪽으로 돌려(pelvis +Y 20 ~ 35, neck/head -Y로 시선 유지) 왼쪽 어깨를 앞으로 내고, 칼은 뒤로 늘어뜨림 자세로 비킵니다.
- `fx`의 새 이름은 웹 `main.js`에서는 무시되고 Unity에서 효과를 붙입니다.

## 진행 순서
1. 위 동작을 moves.js에 추가 → `node web-proto/server.mjs` → 콘솔 `__proto.audit([...새 이름])`으로 기준값 안인지 확인, `__proto.play(name)`으로 확인.
2. `await (await import('/tools/export-unity.js')).exportAll()` → Unity `SOUL/Import Web Export`.
3. Unity 스킬 시스템(카탈로그 7절)은 WASD 조작 세션이 끝난 뒤(`Skills.cs` · `KeyBinds.cs` 충돌 방지).
